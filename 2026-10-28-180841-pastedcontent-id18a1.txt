  What HILD is for

  HILD is a way to build scientific software with an AI agent while you stay in
  charge. You decide what gets built, and you understand how it works. The
  process has five parts:

  1. Agreed authority. You and the agent settle on a bounded piece of work
     before the agent starts it. That agreement is called a scope.
  2. Inspectable change. Proposed work stays separate from accepted work until
     you can examine it.
  3. Meaningful review. Only you accept work. The agent never merges on your
     behalf.
  4. Recoverable state. Goals, decisions and progress are kept in files, so they
     survive past any one chat.
  5. Your own judgment of your understanding. The agent drafts explanations and
     flags what it's unsure of. Only you say what you actually understand.

  The GitHub workflow (scope issues, draft PRs, a plan and journal, an optional
  understanding wiki) is the current reference implementation of these five
  parts. It is the default way HILD achieves them, not what defines HILD. HILD
  isn't a running service. It's a set of instructions, skills and templates that
  live in your repo.
